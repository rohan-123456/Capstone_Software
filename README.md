# Bitcoin Price Prediction Using ARIMA

## Project Overview

This project is a web-based **Bitcoin Price Prediction and Analytics System** that uses historical Bitcoin price data to analyze market trends and predict future prices.

The system uses the **ARIMA (AutoRegressive Integrated Moving Average)** time-series forecasting model to generate a **10-day Bitcoin price forecast**.

## Features

- 📊 Historical Bitcoin price analysis
- 📈 30-day moving average
- 🤖 ARIMA-based price prediction
- 🔍 Actual vs. predicted price comparison
- 📉 MAE and RMSE model evaluation
- 🔮 10-day future price forecasting
- 📊 Interactive charts
- 🌐 Flask API backend
- 💻 Web-based analytics dashboard

## How It Works

1. Historical Bitcoin data is loaded from the CSV dataset.
2. The data is cleaned and sorted according to date.
3. A 30-day moving average is calculated.
4. The dataset is divided into training and testing data.
5. An ARIMA model is trained using the training data.
6. The model is evaluated using MAE and RMSE.
7. The final model is trained using the available historical data.
8. A 10-day future Bitcoin price forecast is generated.
9. The results are displayed through an interactive web dashboard.

## Model

The project uses an **ARIMA (1, 0, 1)** model for Bitcoin price forecasting.

The dashboard displays:

- Current Bitcoin price
- Predicted future price
- Price change
- Percentage change
- Prediction direction
- MAE
- RMSE
- Historical price chart
- Model evaluation chart
- Future forecast chart

## Project Objective

The main objective of this project is to demonstrate how **time-series forecasting and data visualization** can be combined to create a simple Bitcoin price prediction system.

> **Note:** The predictions generated by this project are based on historical data and should not be considered financial advice.
